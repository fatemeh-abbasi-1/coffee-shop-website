# ☕ Coffee Shop Website

A modern and responsive **Coffee Shop Website** built with **React**.  
This project simulates a real-world coffee shop app with menus, product listings, and dynamic data powered by **JSON Server**.

---

## 🚀 Features

- 🏠 Modern, responsive UI built with React
- 📦 Fake REST API using JSON Server
- 🔄 Dynamic data fetching and rendering
- 💬 Modular and clean component structure
- ⚙️ Easy to set up and extend

---

## 🛠️ Tech Stack

- **React** (Frontend Framework)
- **JSON Server** (Mock Backend)
- **Fetch / Fetch API** (Data fetching)
- **React Router** (Navigation)
- **CSS / Tailwind /** (Styling – depends on your setup)
- **Atomic Design**

---

## 📦 Installation & Setup

Clone the repository and install dependencies:

```bash
# Clone project
git clone https://github.com/fatemeh-abbasi-1/coffee-shop-website.git


# Launch json server
json-server --watch db.json --port 3000

# and
npm run dev


```
